# Интерфейс TravelAIChatbot

React-интерфейс с чатом, карточками вариантов, редактором поездки и демонстрационным оформлением. Для полного запуска с PostgreSQL и настройки модели см. [корневой README](../README.md#запуск-с-docker).

## Разработка

Из каталога фронтенда выполните:

```bash
npm ci
npm run dev
```

Запустите FastAPI на порту 8080 по [инструкции локальной разработки](../README.md#локальная-разработка-без-docker). Vite проксирует запросы к API на этот порт.

## Проверки

```bash
npm test
npm run lint
npm run build
```
