# История изменений

## Основные этапы

- Собраны React-интерфейс с чатом и карточками поездки, API FastAPI и каталог на PostgreSQL или SQLite.
- Добавлены OpenRouter, резервные модели Groq и локальный режим для запуска без ключей.
- Реализованы подбор по полному бюджету, сравнение вариантов, семейные тарифы, пересадки и демонстрационные ваучеры.
- Добавлены редактирование дат, времени рейсов, состава гостей и числа номеров, а также оценка погоды на выбранные даты.
- Добавлены автоматические проверки интерфейса и API, проверка секретов перед коммитом и бенчмарк диалогов.
- Подготовлена самостоятельная версия TravelAIChatbot с собственной конфигурацией и документацией.
